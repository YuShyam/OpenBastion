# 語系字典與 78 欄位字寬規格 (Locales & Character Budget)

這裡存放 OpenBastion 的多語系字典檔。系統啟動時會自動載入這層目錄的所有 JSON 檔，作為終端介面文字的單一來源 (SSOT)。

---

## 一、 78 欄位安全線與字寬限制 (Character Budget)

終端畫面寬度強制壓在 78 字元以內，避免不同終端模擬器換行破版。字寬計算使用 `unicodedata.east_asian_width`：
- **全形字元** (繁體中文、日文漢字、假名、全形標點)：視覺寬度計 **2 欄位**。
- **半形字元** (英文字母、數字、半形標點)：視覺寬度計 **1 欄位**。

為了確保在 Windows Terminal、PuTTY、xterm 或 iTerm2 裡邊框都能對齊，各個詞彙有明確的字寬預算：

| 字典鍵值 (Key) | 建議字寬上限 | 說明與範例 | 超出上限時的處理 |
| :--- | :---: | :--- | :--- |
| `menu.title` | ≤ 74 寬度 | 選單頂部置中標題（如 `OpenBastion 主機選單` 佔 20 寬度） | 超出 74 寬度時自動截斷補 `…` |
| `menu.col_index` | ≤ 4 寬度 | 序號欄位標題（如 `#` 佔 1 寬度） | 超出 4 寬度時自動截斷補 `…` |
| `menu.col_name` | ≤ 17 寬度 | 主機名稱欄位標題（如 `主機名稱` 佔 8 寬度） | 超出 17 寬度時自動截斷補 `…` |
| `menu.col_address` | ≤ 22 寬度 | 端點 IP:Port 欄位標題（如 `IP:埠號` 佔 7 寬度） | 超出 22 寬度時自動截斷補 `…` |
| `menu.col_internal_nat` | ≤ 22 寬度 | 內網 NAT 欄位標題（如 `內網NAT` 佔 7 寬度） | 超出 22 寬度時自動截斷補 `…` |
| `menu.col_os` | ≤ 15 寬度 | 作業系統欄位標題（如 `作業系統` 佔 8 寬度） | 超出 15 寬度時自動截斷補 `…` |
| `menu.col_alias` | ≤ 15 寬度 | 主機別名欄位標題（如 `別名` 佔 4 寬度） | 超出 15 寬度時自動截斷補 `…` |
| `menu.col_status` | ≤ 12 寬度 | 狀態欄位標題（如 `狀態` 佔 4 寬度） | 超出 12 寬度時自動截斷補 `…` |
| `menu.col_rack` | ≤ 12 寬度 | 機櫃位置欄位標題（如 `機櫃位置` 佔 8 寬度） | 超出 12 寬度時自動截斷補 `…` |
| `menu.view_system` | ≤ 10 寬度 | 系統視圖名稱（如 `系統模式` 佔 8 寬度） | 帶入導航列 `{view}` 佔用預算 |
| `menu.view_idc` | ≤ 10 寬度 | 機房視圖名稱（如 `機房模式` 佔 8 寬度） | 帶入導航列 `{view}` 佔用預算 |
| `menu.nav_bar` | **≤ 45 寬度** | 底部左側操作導航列（包含 `{view}` 替換後的長度） | 超長時最右側會被外框截斷補 `…` |
| `menu.page_info` | **≤ 25 寬度** | 底部右側頁碼資訊（如 `第 1/1 頁 (共 1 台)` 佔 18 寬度） | 超長時與導航列合併截斷補 `…` |
| `common.online` | ≤ 8 寬度 | 狀態標籤（如 `在線` 佔 4 寬度） | 超出欄位寬度時截斷補 `…` |
| `common.exit` | ≤ 6 寬度 | 退出動作詞（如 `退出` 佔 4 寬度, `Exit` 佔 4 寬度） | 終端提示用 |

## 二、 超長文字截斷處理 (Truncation)

超出長度的文字由 `core.menu.AnsiSanitizer` 自動處理：
1. **表格欄位截斷 (`fit_width`)**：
   當資料或標題長度超出欄位設定時，會在最後一格補上 `…`（省略號），不會往右推擠其他欄位。
2. **整行外框截斷 (`render_box_line`)**：
   每行內容外層都包在 `| {padded} |` 裡面，內部可用寬度固定是 74 格。如果整行文字（包含導航列與頁碼）超過 74 格，最右邊會直接截斷補 `…`，確保最右側的邊框 `|` 剛好落在第 78 格，不會折行破版。

## 三、 新增語系步驟 (Auto-Discovery)

新增語言不需要修改任何 Python 程式碼：

1. 在 `locales/` 目錄新增 `<語系代碼>.json`（例如 `ja_JP.json`）。
2. 在 JSON 頂部加入 `_metadata`：
   ```json
   {
     "_metadata": {
       "name": "日本語",
       "aliases": ["ja", "jp", "ja_jp", "japanese"]
     },
     "menu.title": "OpenBastion ホストメニュー",
     ...
   }
   ```
3. 重啟服務或建立新連線，系統會自動載入該檔案：
   - 支援用代碼或別名切換（例如 `lang ja`、`lang japanese`）。
   - 在終端輸入 `lang` 或 `lang ?`，新語言會自動出現在支援清單中。
